# Font library

A curated starting set, grouped by voice. Always confirm the license, glyph coverage and axes on the foundry or specimen page at the time of use; axes listed here are the commonly published ranges. Google Fonts faces are under the SIL Open Font License unless noted. Fontshare faces use the ITF Free Font License. Commercial faces need a web license sized to the site's traffic.

## Loading snippets

Google Fonts with variable ranges (axis tags alphabetical, lowercase before uppercase):

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght,SOFT,WONK@9..144,100..900,0..100,0..1&family=Hanken+Grotesk:wght@100..900&display=swap">
```

Self-hosted with Fontsource (variable packages register the family as "Name Variable"):

```js
import '@fontsource-variable/fraunces';
import '@fontsource-variable/hanken-grotesk';
```

Self-hosted WOFF2 with a metric-matched fallback. Compute the override percentages for your exact pair (next/font, fontaine and Capsize calculate them); the values below only show the shape.

```css
@font-face {
  font-family: "Display";
  src: url("/fonts/display-var.woff2") format("woff2");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "Display Fallback";
  src: local("Times New Roman");
  size-adjust: 104%;
  ascent-override: 92%;
  descent-override: 24%;
  line-gap-override: 0%;
}

:root {
  --font-display: "Display", "Display Fallback", serif;
}
```

```html
<link rel="preload" href="/fonts/display-var.woff2" as="font" type="font/woff2" crossorigin>
```

Next.js (`next/font` self-hosts and generates fallback metrics):

```ts
import { Fraunces, Hanken_Grotesk } from 'next/font/google';

export const display = Fraunces({ subsets: ['latin'], axes: ['SOFT', 'WONK', 'opsz'], variable: '--font-display' });
export const text = Hanken_Grotesk({ subsets: ['latin'], variable: '--font-text' });
```

Subset to the scripts you publish, preload only the fonts used in the first view, and prefer one variable file over many static weights when more than three weights are needed.
